RFSAT Rover Configurator

Builds the $SPSET command set for the RTK Everywhere RFSAT firmware: Wi-Fi networks, up to four NTRIP correction sources in priority order, Bluetooth and Galileo HAS fallback. Send it over USB from Chrome, or paste it into a Bluetooth terminal.

Wi-Fi networks

Tried in order. Up to four. Leave unused rows empty.

Correction sources

Source 1 has priority. On a failure (no connection, no response, rejected login or mount point, or 30 s without RTCM) the rover moves to the next source in about 2 s. Keep sources within 2–4 km of the work area for sub-centimetre fixes.

Profile file

Save the form as JSON to reuse it on the next unit. Passwords are included, so keep the file private. Nothing is stored in the browser.
